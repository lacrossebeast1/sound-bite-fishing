# Sound Bite Fishing Planner

Clean Next.js app for Westport, Norwalk, Darien, Fairfield, and Greenwich, CT.

Uses NOAA CO-OPS tide predictions and National Weather Service hourly wind forecasts.
Shows first light, sunrise, sunset, last light, high/low tides, wind speed/direction,
and a transparent fishing-window score.

Important: this clean project intentionally has NO postcss.config.*, NO Tailwind
configuration, and NO Tailwind dependency. TypeScript dependencies are included.

Vercel:
1. Put the contents of this folder in a fresh GitHub repository.
2. Import that repository into Vercel.
3. Leave Build Command as npm run build.
